## 📁 Estrutura do News-Caster Studio
* **Frontend:**
  * `index.html` (Interface principal do estúdio)
  * `assets/css/style.css` (Estilos principais)
  * `assets/js/app.js` (Controlador da UI e integrações)
* **Backend (APIs PHP):**
  * `api/generate.php` (Geração de pautas/notícias)
  * `api/publish.php` (Integração de publicação via REST API para o Notícia Baré)
  * `api/trends.php` (Consulta de trending topics/temas em alta)
